# C2 페이지 틀·CSS spec 리뷰 기록

검토 대상은 `docs/superpowers/specs/2026-10-04-c2-page-frame-design.md`이고, 렌즈별 원본은 같은 이름의 폴더에 있다.

## 실행 개요

렌즈는 lens-grounding, lens-consistency, lens-adversarial, lens-fit을 읽기 전용 에이전트로 따로 실행했다. 렌즈를 한 번씩만 실행했다. 선행연구 렌즈는 붙이지 않았다. 상위 설계가 정한 CSS·템플릿 개선을 구현하는 컴포넌트 설계라 발동 기준에 들지 않는다.

## 병합한 지적

- **제목 체계 검사의 충돌:** 페이지형 `h2`에 결론 문장 검사를 걸면 고정 견본(모두 페이지형, 명사구 `h2`)이 새 규칙에, 결론 제목을 쓴 템플릿이 기준 규칙(`--base-checks`)에 걸린다. 결론 없는 페이지(요약·목록·부록)와 `.gist`의 '요약'도 위반이 된다. 페이지형 판별 기준과 원본 대조 방식이 없어 기존 문서 수정 때 모든 `h2`가 위반이 된다. C3 병합 전까지 SKILL.md와 검사기가 반대로 말한다. (grounding, consistency, adversarial 공동)
- **넓은 표:** 셀 폭 확보가 없어 `table-col-390` 기준선 실패(39.6px, 34.5px)가 남는다. 스크롤 단서를 문서 코드로 만들면 고정 견본에 반영되지 않고, 숨은 페이지·창 크기 변경·인쇄 처리가 없다. (grounding, consistency, adversarial 공동)
- **검증 명령:** 고정 견본의 `hash-nav`는 C2 변경과 무관하게 실패한다. `--judge-hash-nav` 없이는 템플릿의 `hash-nav`가 판정되지 않는다. 템플릿 관리 블록 재빌드 단계가 없다. 하락 금지·판정 차례·기준 규칙 병행 검사가 빠졌다. 자가 점검의 입력과 '3회' 뜻이 없다. (consistency, grounding)
- **색:** 막대 대비는 `--tint`에서 더 낮고(2.34, 2.47), 밝은 `--s4`는 `--tint`에서 2.95다. 어두운 테마 계열 색차(11.14)도 미달이다. `--accent-2`를 진하게 하면 지나온 도형과 현재 도형의 구분이 줄어든다. 색차만 보고 고르면 색상 계열과 `--s1`(강조색·캔들 하락색)이 바뀔 수 있다. (grounding, adversarial)
- **페이지 틀:** `.pno`를 무조건 숨기면 스크립트가 없을 때 번호가 사라진다. 용어 목록은 제목이 필요하고, 고정 폭은 긴 용어가 넘친다. '고정 견본에 C2 변경이 들어가지 않는다'는 과장이다(CSS는 들어간다). (adversarial, grounding)
- **C3용 화면 요소:** 확인 상태 글이 상위 설계와 다르고, CSS 생성 글은 DOM 글에서 빠진다. 대체됨 배너의 색 토큰이 없고 `--neg`는 손실 뜻과 겹친다. 세 요소의 검증 단계가 없다. (consistency, adversarial)
- **문서 틀:** 산출 계약(plan 위치, 마커, 브랜치, 리포트)과 이름 절, 상위 설계 우선 문장이 없다. (consistency)
- **문체와 용어:** 절 첫 문장 누락, 개수 지칭, 내부 이름 미풀이, 판정 값 없는 기준, 여러 문장 불릿, 중의 문장. (fit)
