# 보고서 화면 체크리스트

이 파일은 보고서 품질을 판정하는 이진 체크리스트다. 검토자는 `eval/shoot.py` 출력 폴더의 장면과 글만 보고 항목마다 '예'·'아니오'·'해당 없음'으로 답한다. '예'가 바람직한 상태다. 적용 대상은 그 항목을 고칠 수 있는 컴포넌트다. `motion`은 애니메이션·도식·차트, `layout`은 색·배치·페이지 틀, `content`는 문장·절 구성·근거·결정 요청이다. 질문의 '노드'는 도식 안의 도형(상자, 마름모, 막대)을 가리킨다. '설명 상자'는 애니메이션이 노드 옆에 보여 주는 글 상자이고, '자막'은 그림 아래에 나오는 단계 문장이다.

| id | 범주 | 적용 대상 | 질문 | 대응 결함 |
|---|---|---|---|---|
| `anim-readable` | 이해 용이성 | motion | 애니메이션 단계 장면마다, index.json의 `seconds`(그 단계의 연출과 머무는 시간을 합친 길이)가 그 장면에 새로 나온 자막과 설명 상자 글을 읽는 데 필요한 시간 이상인가? 필요한 시간은 1초에 글자 수 ÷ 8초를 보탠 값이고, 글자 수는 공백을 빼고 세며 숫자 묶음은 1자로 센다. 한 단계라도 모자라면 '아니오'다. 애니메이션이 없거나, 단계 장면이 단계 넘김 방식(독자가 '다음'을 눌러 넘기는 방식, index.json의 `mode`가 `step`)이면 해당 없음이다. | 애니메이션 단계가 읽기 전에 넘어간다 |
| `note-beside` | 구성 | motion | 모든 애니메이션의 모든 단계 장면에서, 그 단계의 설명이 강조된 노드 바로 옆의 설명 상자에 나오는가? 설명 상자 없이 그림 아래 자막만 있는 단계가 하나라도 있거나, 설명 상자가 강조된 노드와 떨어져 있으면 '아니오'다. 애니메이션이 없으면 해당 없음이다. | 설명이 도형에서 떨어져 하단 자막으로만 나온다 |
| `focus-note-one-screen` | 이해 용이성 | motion | 애니메이션 단계 장면(1280×800 한 화면)마다, 강조된 노드와 그 단계의 설명(설명 상자나 자막)이 둘 다 화면 안에 보이는가? 애니메이션이 없으면 해당 없음이다. | 강조 노드와 설명을 한 화면에서 함께 볼 수 없다 |
| `current-vs-past` | 심미성 | motion | 여러 노드를 차례로 강조하는 모든 애니메이션의 모든 단계 장면에서, 현재 강조된 노드와 이미 지나온 노드가 색이나 채움으로 서로 다르게 보이는가? 두 노드가 같은 모양인 단계 장면이 하나라도 있으면 '아니오'다. 차례 강조가 없으면 해당 없음이다. | 현재 노드와 지나온 노드가 구분되지 않는다 |
| `baseline-kept` | 논리 전개 | motion | 전후 비교 애니메이션의 마지막 단계 장면에 비교 기준 막대나 바뀌기 전 값이 함께 남아 있는가? 전후 비교 애니메이션이 없으면 해당 없음이다. | 전후 비교의 기준선이 끝 장면에서 사라진다 |
| `svg-text-390` | 심미성 | motion | 390 폭 장면에서 도식·차트·애니메이션 안의 글자를 확대하지 않고 읽을 수 있는가? 글자가 '…'로 줄었거나 읽기 어려울 만큼 작으면 '아니오'다. 도식이 가로 스크롤 상자 안에서 오른쪽으로 이어지고, 밀어 볼 수 있다는 단서(안내 문구)가 그 도식 위에 보이면 화면 밖 부분은 잘림으로 보지 않는다(넓은 표와 같은 기준). 단서 없이 잘리면 '아니오'다. 도식·차트가 없으면 해당 없음이다. | 390 폭에서 도식 글자가 읽을 수 없게 작아진다 |
| `table-cols-390` | 이해 용이성 | layout | 390 폭 장면에서 모든 표의 모든 칸이 낱말이나 식별자(영문 이름 포함)를 중간에서 끊지 않고 읽히는가? 한두 글자 폭으로 잘린 열이 있거나, 'lens-/grounding'처럼 낱말 중간에서 줄이 바뀐 칸이 하나라도 있으면 '아니오'다. 표가 없으면 해당 없음이다. | 390 폭에서 표를 읽기 어렵거나 가로 스크롤 단서가 없다 |
| `table-scroll-cue-390` | 이해 용이성 | layout | 390 폭 장면에서 화면 오른쪽으로 잘려 이어지는 표마다, 가로로 밀어 볼 수 있다는 단서(그림자, 안내 문구, 잘린 열 표시)가 보이는가? 잘리는 표가 없으면 해당 없음이다. | 390 폭에서 표를 읽기 어렵거나 가로 스크롤 단서가 없다 |
| `single-page-number` | 심미성 | layout | 페이지 장면마다 '2 / 8' 같은 페이지 번호가 한 번만 보이는가? 페이지 번호가 없는 문서는 해당 없음이다. | 페이지 번호가 두 번 보인다 |
| `glossary-layout` | 심미성 | layout | 용어 풀이 목록이 있는 장면에서, 목록에 제목이 있고 각 용어와 풀이가 같은 줄에 가까이 붙어 짝이 바로 읽히는가? 용어 풀이 목록이 없으면 해당 없음이다. | 용어 풀이 배치가 깨진다 |
| `titles-tell-story` | 논리 전개 | content | 페이지형 문서는 페이지 제목만, 단일 문서는 절마다 제목 바로 아래 첫 문장(본문 제목)만 차례로 읽어도 문서의 결론과 논지가 이어져 보이는가? 단일 문서의 절 제목(`h2`)은 목차 구실을 하는 명사구가 정상이므로 그것만으로 '아니오'로 보지 않는다(사용자 원칙 TITLE-LAYERS). 모든 문서에 적용한다. | 제목만 읽으면 논지가 보이지 않는다 |
| `no-triple-repeat` | 구성 | content | 각 페이지에서 같은 사실(같은 단계 목록, 같은 수치, 같은 소속 관계)을 불릿·도식·표 중 두 형식 이상이 되풀이하는 곳이 없는가? 한 형식이 다른 형식에 없는 정보를 보태지 않고 같은 내용을 다시 보이면 되풀이로 본다. 애니메이션의 설명 상자와 자막의 관계는 이 항목에서 보지 않는다. 되풀이가 한 곳이라도 있으면 '아니오'다. 모든 문서에 적용한다. | 같은 사실을 불릿·도식·표로 반복한다 |
| `decision-recommend` | 사용자 만족도 | content | 독자에게 결정을 요청하는 항목마다 권장안과 그 이유가 적혀 있는가? 결정 요청이 없으면 해당 없음이다. | 결정 요청에 권장안이 없다 |
| `claims-sourced` | 사용자 만족도 | content | 수치나 단정 주장마다 같은 페이지 안의 표·그림·출처 목록에서 근거를 찾을 수 있는가? 다른 페이지에 있는 근거는 인정하지 않으며, 근거 없는 주장이 한 곳이라도 있으면 '아니오'다. 모든 문서에 적용한다. 단일 문서에서는 '같은 페이지'를 '같은 절'로 본다. 요약 절의 줄은 같은 줄에 근거가 있는 절 이름이나 원자료 위치를 밝히면 근거가 있는 것으로 본다. | 근거 없는 주장이 있다 |

## 뺀 항목

체크리스트 판별력 확인(문구 보정 두 번)에서도 흔들림이 남아 아래 항목을 뺐다. 기록은 `eval/baseline/checklist-agreement.md`에 있다.

- **bullet-table-agree(논리 전개, content):** 대응 결함 '불릿과 표의 내용이 서로 다르다'. 두 번째 보정 뒤 03-groups의 결함은 세 번 모두 잡았으나 04-rules에서 세 결과가 서로 달랐다. 이 결함은 지금 체크리스트로 측정하지 않는다.
